## Запрос / мотивация
Регламент Winter 2026: публичный GitHub-репозиторий должен содержать ливрею для масс-старта
(по ней различают машины на стартовой решётке). В репо её не было — она жила только в локальном
TORCS у Hlib: `C:\torcs\torcs\drivers\scr_server\0\car1-ow1.rgb` (изменён 2026-07-01, остальные
текстуры слотов — заводские).

Требования из «TORCS CAR customization guide» организаторов: SGI `.rgb`, стороны — степени двойки,
имя файла как у оригинала, файл лежит в `drivers/scr_server/<слот>/`. Регламент п. 6.5: без брендинга
IBM, чужих товарных знаков и оскорбительного содержания.

## Что меняем
- `livery/car1-ow1.rgb` — текстура как есть (512×512 RGBA, SGI).
- `livery/car1-ow1-preview.png` — PNG-копия для просмотра на GitHub.
- `livery/README.md` — что это и как установить.
- `.gitattributes` — `*.rgb` и `*.png` как `binary` (чтобы git не трогал окончания строк).
- `README.md` — ссылка на ливрею в шапке.

Код и параметры драйвера не меняются.

## Как проверить
1. На GitHub открывается `livery/README.md` с картинкой.
2. MD5 `livery/car1-ow1.rgb` совпадает с локальным `drivers\scr_server\0\car1-ow1.rgb`.
3. Скопировать файл в слот 0, перезапустить TORCS — машина в ливрее.

## Заметки / открытые вопросы
- **Машина соревнования не подтверждена.** Гайд организаторов показывает `car1-trb1`, у нас слот 0 —
  `car1-ow1`. Если гонка будет на `car1-trb1`, нужна вторая ливрея `car1-trb1.rgb` (вопрос задан
  организаторам 2026-11-27).
- На ливрее логотип университета (TUKE). Это не IBM и не коммерческий бренд, но п. 6.5 запрещает
  «third-party trademarks» — при сомнениях уточнить у организаторов.
