## Запрос / мотивация
Точка отсчёта: как едет основной драйвер `snakeoil3_gym.py` (`drive_example`) на целевой трассе
до любых улучшений.

## Что меняем
Ничего. Замер текущего поведения.

### Параметры драйвера на момент замера
| Параметр | Значение |
|----------|----------|
| `target_speed` | 300 км/ч |
| Руль к углу трассы | `angle * 15 / PI` |
| Руль к центру | `trackPos * 0.10` |
| Газ | `±0.01` за шаг к целевой скорости |
| Тормоз | **нет** |
| TCS | `accel -= 0.2`, если пробуксовка задних колёс > 5 |
| Передачи (км/ч) | 50 / 80 / 110 / 140 / 170 |
| Датчики `track` | 19 лучей, сгущены вперёд: −45…45°, индекс 9 = 0° (прямо) |

## Как проверить
TORCS (Windows, Practice: corkscrew, scr_server) → `python snakeoil3_gym.py`.

## Результат
- Круг **не завершён**.
- Машина разгоняется на прямой, перед поворотом не успевает сбросить скорость
  и врезается в стену, пытаясь повернуть.
- Причина (по коду): торможения нет совсем; газ уменьшается лишь на 0.01 за шаг
  (≈2 с от полного газа до нуля), а целевая скорость 300 км/ч не зависит от того, что впереди.

## Заметки / открытые вопросы
- Следующий шаг — торможение перед поворотами по передним датчикам `track` (отдельная спека).
  Перед этим — логгер телеметрии (спека 0006), чтобы сравнивать заезды по цифрам.
- Время круга для сравнения появится, когда драйвер начнёт проходить круг целиком.
