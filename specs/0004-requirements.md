## Запрос / мотивация
В проекте работают три человека, а список зависимостей нигде не был записан.
Нужно, чтобы окружение у всех было одинаковым.

## Что меняем
1. `requirements.txt` — только то, что реально импортирует код проекта:

| Пакет | Версия | Кем используется |
|-------|--------|------------------|
| — | — | `snakeoil3_gym.py` (основной драйвер) — только стандартная библиотека |
| numpy | 2.4.6 | `sample_agent.py`, `example_experiment.py`, `gym_torcs.py` |
| matplotlib | 3.10.9 | `sample_agent.py` |

   Версии — как в рабочем окружении Hlib (Python 3.11.9).
   `gym` (для `gym_torcs.py`) не включён: устаревший пакет, а сам `gym_torcs.py` работает только в Linux.
2. `CONTRIBUTING.md` — раздел «Окружение»: как создать venv и поставить зависимости.

Пакеты из локального окружения, которые код проекта не использует (torch, tensorflow, keras,
scikit-learn, pandas и др.), сознательно не включены. Добавлять — когда появится код, который их импортирует.

## Как проверить
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -c "import sample_agent, snakeoil3_gym"
```

## Результат
Проверено в чистом venv (Python 3.11.9): установка без ошибок, импорт `sample_agent` и `snakeoil3_gym` проходит.
