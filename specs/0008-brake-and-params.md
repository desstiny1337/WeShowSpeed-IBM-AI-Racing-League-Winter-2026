## Запрос / мотивация
Исходный драйвер (спеки 0005/0006) едет с `target_speed=300` без тормоза и вылетает на
distFromStart ≈ 425 м Corkscrew на ~242 км/ч, хотя стена видна дальномером `track[9]` за ~170 м.
Нужно: торможение, рассчитанное по дальномерам (универсально — трассы на соревновании случайные,
никаких таблиц под конкретную трассу), ABS/TCS, передачи по оборотам, выезд с обочины и
разворот задним ходом при застревании. Все настраиваемые числа — параметры, которые можно
переопределить JSON-файлом (`--params`), чтобы потом оптимизировать их CMA-ES на HPC.

## Что меняем

### Файл параметров
- `DEFAULT_PARAMS` (dict) вверху `snakeoil3_gym.py`, у каждого ключа комментарий.
- `--params, -P <file.json>` — JSON-объект, переопределяет любые ключи. Неизвестный ключ,
  нечисловое значение или нечитаемый файл → понятная ошибка и выход (до подключения к серверу).
  Только stdlib (`json`).
- `Client.params` — действующие параметры (копия `DEFAULT_PARAMS` или результат `load_params`).
  `drive_example(c, params=None)` берёт `params`, иначе `c.params`, иначе `DEFAULT_PARAMS` —
  старые вызовы `drive_example(c)` работают как раньше.
- При старте печатается одна строка `params (<файл|defaults>): {...}`; в сводке `--log` добавлена
  строка `params: <файл|defaults>`. Колонки CSV и остальная логика логгера не менялись.
- `params/default.json` — копия `DEFAULT_PARAMS` (шаблон для HPC-пайплайна).
- Протокольная часть `Client` (init-строка, сокет, разбор) не тронута; добавлены только опция
  командной строки и два атрибута.

### Логика `drive_example()`
Дальномеры: init-строка `-45 -19 -12 -7 -4 -2.5 -1.7 -1 -.5 0 .5 1 1.7 2.5 4 7 12 19 45` (градусы),
отрицательный угол — влево (проверено по `sensors.cpp` сервера), `track[9]` — прямо, до 200 м,
вне трассы −1. Углы продублированы в `TRACK_SENSOR_ANGLES`.

1. **Целевая скорость** (км/ч ↔ м/с через 3.6):
   - `d_ahead = max(track[9-k .. 9+k])`, `k = ahead_halfwidth`;
   - `v_target = 3.6 · sqrt((v_corner/3.6)² + 2·decel·max(0, d_ahead − dist_margin))`;
   - `v_target −= curv_speed_gain · |угол самого длинного луча, °|` (подсказка о кривизне; по умолчанию выкл.);
   - clamp в `[v_min, v_max]`; вне трассы (`|trackPos|>1`) ещё `min(·, offtrack_speed)`.
   - При насыщении датчиков (200 м) и параметрах по умолчанию потолок ≈ 253 км/ч.
     Пример исходного вылета: 170 м до стены → `v_target` ≈ 234 км/ч, на 242 км/ч сразу тормоз ≈ 0.83.
2. **Газ/тормоз:** `err = v_target − speedX`.
   - `err < −brake_hyst` → `accel=0`, `brake = clip(brake_gain·(−err), 0, 1)`;
   - иначе `brake=0`, `accel = clip(accel_gain·(err + brake_hyst), 0, 1)`.
   - **ABS** (при `speedX > abs_min_speed`): `slip = max_i (v − ω_i·r_i)/v` по 4 колёсам
     (`wheelSpinVel` = FR, FL, RR, RL; радиусы car1-ow1 перед 0.3024 м, зад 0.3151 м);
     если `slip > abs_slip` → `brake *= clip(1 − abs_gain·(slip − abs_slip), 0, 1)`.
   - **TCS** (при `speedX > tcs_min_speed`, задний привод): `slip = (ω̄_rear·r_rear − v)/v`;
     если `slip > tcs_slip` → `accel *= clip(1 − tcs_gain·(slip − tcs_slip), 0, 1)`.
3. **Руль** (`steer > 0` — влево): `steer = steer_angle_gain·angle − pos_gain·trackPos − steer_ray_gain·рад(угол длинного луча)`,
   `pos_gain = offtrack_pos_gain` вне трассы, иначе `steer_pos_gain`; луч вне трассы не используется; clip −1..1.
   Самый длинный луч — argmax `track`, при равенстве — ближайший к 0°.
4. **Передачи** по `rpm` текущей передачи сервера (`S['gear']`): `<1` → 1; `rpm > gear_up_rpm` → +1
   (до `gear_max`); `rpm < gear_down_rpm` → −1 (не ниже 1). Передаточные числа ow1 (3.9/2.9/2.3/1.87/1.68/1.54)
   дают после переключения вверх ≥ 0.74·17500 ≈ 13000 > 11000 — без «звона».
5. **Застревание:** если `|speedX| < stuck_speed` и `|angle| > stuck_angle` дольше `stuck_steps` шагов →
   `reverse_steps` шагов задним ходом: `gear=-1`, `accel=reverse_accel`, `brake=0`,
   `steer = clip(−reverse_steer_gain·angle)` (руль инвертирован). Состояние хранится в `c._drive_state`.

## Заметки / открытые вопросы
- `decel`, `v_corner`, `dist_margin` — главные кандидаты для CMA-ES; потолок скорости на прямой
  ограничен дальностью датчиков (200 м) и `decel`.
- Центральные лучи в длинном повороте упираются во внешнюю стену → цель близка к `v_corner` даже в быстрых
  дугах. Если будет медленно — пробовать `ahead_halfwidth` больше, `steer_ray_gain`/`curv_speed_gain` > 0.
- Соперники (`opponents`) пока не учитываются.
